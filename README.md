# Book Counter  📚

A simple and elegant local web application for tracking read books and pages. Built with Python (Flask), SQLite, and a responsive HTML/CSS/JavaScript interface.

## Features
- **Add Books:** Easily save new books with titles, authors, and page counts.
- **Report View:** View all saved books in an Excel-style table.
- **Edit & Delete:** Update or remove book entries directly from the report window.
- **Live Statistics:** Real-time tracking of total books read and total pages.

## Technologies Used
- **Backend:** Python, Flask, SQLite
- **Frontend:** HTML5, CSS3, JavaScript

## Getting Started / Installation

Follow these steps to run the application locally or on a Raspberry Pi:


pip install Flask

python backend/init_db.py

python backend/main.py
